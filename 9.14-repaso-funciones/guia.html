L'exercice, expliqué simplement (en français)

Bonjour ! Imagine que l'ordinateur ne sait pas lire comme toi : il ne « comprend » pas un prénom ou un nom de famille. Il voit seulement une chaîne de caractères — des lettres, des espaces, des chiffres, etc.

Ton exercice te demande de créer une petite règle automatique (une fonction) qui répond à une seule question :

« Est-ce que ce texte ressemble à un nom de personne acceptable ? »

C'est quoi une « fonction » ?

Pense à une machine à café :

  1. Tu lui donnes quelque chose (entrée) : par exemple le texte "Anita de la Rosa D'Onoffrio ".
  2. La machine fait un travail précis (traitement) : elle vérifie caractère par caractère.
  3. Elle te rend une réponse (sortie) : vrai ou faux (en programmation : true / false).

En JavaScript, ça ressemblerait à l'idée :

miFuncion("Anita de la Rosa D'Onoffrio ")  // → true (si tout est valide)
miFuncion("Ana123")                        // → false (il y a des chiffres)

Tu ne « montres » pas le résultat à l'écran dans l'exercice de base : la fonction retourne juste vrai ou faux. C'est le cœur du travail.

Qu'est-ce qu'un nom « valide » ici ?

L'énoncé dit : seulement des lettres et des apostrophes (').

  • Lettres : A, n, í, é, etc. (souvent aussi les lettres accentuées des noms espagnols ou français).
  • Apostrophe : le petit signe dans des noms comme D'Onoffrio ou O'Brien.

Ce qui ne devrait pas être accepté (en principe) :

  • des chiffres : Ana3
  • des symboles : @, #, - (sauf si ton professeur les autorise explicitement)
  • parfois la ponctuation : ., ,, !

Le piège de l'exemple (important)

Ton exemple :

"Anita de la Rosa D'Onoffrio "

contient des espaces entre les mots et un espace à la fin.

Or l'énoncé dit « seulement lettres et apostrophes ». Donc soit :

  1. ton professeur accepte aussi les espaces entre les mots (très courant pour les noms complets),
  2. soit il faut ignorer les espaces au début et à la fin (trim) et peut‑être autoriser les espaces entre les mots.

À clarifier avec ton professeur : les espaces sont-ils autorisés ? Sans ça, l'exemple "Anita de la Rosa..." ne pourrait pas renvoyer true avec la règle stricte « lettres + apostrophes uniquement ».

Comment la machine « vérifie » (sans code compliqué)

Imagine que tu lis le texte lettre par lettre, comme un professeur qui corrige une copie :

Caractère Verdict
A, n, íOK
' dans D'OnoffrioOK
espace (si autorisé)OK
5Pas OK → tout le nom est invalide
@Pas OK

Si tous les caractères passent la règle → la fonction renvoie vrai.
Dès qu'un seul caractère est interdit → faux.

Pourquoi on fait cet exercice ?

Ce n'est pas seulement pour les noms. Tu t'entraînes à :

  1. Découper un problème : « qu'est-ce qui est autorisé ? »
  2. Parcourir du texte caractère par caractère (ou utiliser une expression régulière plus tard).
  3. Retourner un booléen : oui/non, valide/invalide.
  4. Tester des cas : nom simple, nom avec apostrophe, nom avec chiffre, chaîne vide, etc.

C'est la base de beaucoup de formulaires sur le web (inscription, réservation, etc.).

Les 3 éléments du DOM utilisés par JavaScript (getElementById)

Dans index.html, seuls ces trois éléments ont un id et sont reliés au JS dans la section DECLARACIÓN DE VARIABLES de app.js :

id dans le HTML Balise Variable dans app.js À quoi ça sert
formTexto <form> formulario Écouter l'envoi du formulaire (submit)
texto <input type="text"> inputNombre Lire le nom saisi par l'utilisatrice
resultado <div> zonaResultado Afficher « verdadero » ou « falso »

À retenir : seule la fonction principale (funcionPrincipal) modifie le DOM (lit inputNombre, écrit dans zonaResultado). Le bouton Validar n'a pas besoin de id : il déclenche le submit du formulario.

En la clase del botón, qué significa cada palabra

border-[#7ec8e8]   → color del borde
bg-[#7ec8e8]       → color de fondo (background)
text-[#0a2a4a]     → color del texto
hover:border-...   → borde al pasar el ratón
hover:bg-...       → fondo al pasar el ratón
hover:text-...     → texto al pasar el ratón

[#7ec8e8] es la forma en Tailwind de decir: «usa este color exacto».

Resumen : no son nombres raros de programa: son pinturas — un azul claro para el botón, un azul un poco más oscuro al hover, y un azul oscuro para las letras, para que se vean bien sobre el claro (como el tono del fondo noche.webp). Si quieres un solo azul para todo el botón, se puede simplificar; ahora hay varios tonos para que se note al pasar el ratón.

Résumé en une phrase

Tu dois écrire une fonction juge : elle reçoit un texte, vérifie que chaque caractère respecte les règles du nom (lettres, apostrophes, et probablement les espaces selon ton cours), et répond true si tout va bien, false sinon.
