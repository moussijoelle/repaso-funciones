Guía: conversión Celsius ↔ Fahrenheit

Repaso de funciones — misma lógica que el diagrama del formulario (lee, valida, llama, muestra).

1. En qué consiste el ejercicio

Debes crear una función (una pequeña «máquina» o receta en código) que cambie una temperatura de una unidad a otra:

  • de Celsius (°C) a Fahrenheit (°F), o
  • de Fahrenheit a Celsius.

Ejemplo del enunciado:

miFuncion(0, "C")  →  32°F

Significa: «Tengo 0 grados Celsius; conviértelos a Fahrenheit». El resultado debe ser 32, porque en esa escala el agua congela a 32 °F (no a 0).

¿Qué es una función?

  1. Le das datos de entrada (parámetros).
  2. Ella hace un cálculo.
  3. Te devuelve un resultado con return.

En este ejercicio sueles necesitar dos parámetros:

Parámetro Para qué sirve
Un número La temperatura (por ejemplo 0, 100, -5)
Una letra ("C" o "F") Indica desde qué unidad partes (y hacia cuál conviertes, según el enunciado del profe)

En una frase: escribe una función que reciba una temperatura y su unidad de partida, aplique la fórmula correcta y devuelva el valor en la otra unidad (a veces también con el símbolo, por ejemplo 32°F).

2. Fórmulas de conversión

Celsius → Fahrenheit

°F = °C × (9/5) + 32

Ejemplo: 0 × 9/5 + 32 = 32

Fahrenheit → Celsius

°C = (°F − 32) × (5/9)

Ejemplo: (32 − 32) × 5/9 = 0

La función debe:

  1. Mirar si el segundo parámetro es "C" o "F".
  2. Aplicar la fórmula que corresponda.
  3. Devolver el resultado con return.

3. ¿Qué es Fahrenheit?

Fahrenheit (°F) es otra forma de medir la temperatura, como Celsius (°C), pero con otra escala: los números no coinciden con los de Celsius.

Se debe al físico Daniel Gabriel Fahrenheit. Se usa sobre todo en Estados Unidos; en España y en la mayor parte del mundo se usa más Celsius.

Hecho Celsius (°C) Fahrenheit (°F)
El agua se congela 0 °C 32 °F
El agua hierve 100 °C 212 °F
Temperatura corporal (aprox.) 37 °C ~98,6 °F

Misma sensación de frío o calor, otros números en el termómetro. Por eso 0 °C = 32 °F es un buen test para comprobar que tu función funciona.

4. Misma lógica que el diagrama de clase (otro ejercicio, mismo esquema)

En la pizarra el ejemplo era contar caracteres (cuentaCaracteres). En este ejercicio la función concreta es convertir temperatura, pero el flujo es el mismo:

En el diagrama En conversión de temperatura
Formulario El usuario escribe la temperatura y la unidad (C o F)
La «oreja» (event listener) Al pulsar un botón (o al cambiar un valor), se ejecuta el código
Función main Orquesta todo: lee, valida, llama, muestra
cuentaCaracteres(cadena) miFuncion(valor, unidad) o similar
return Devuelve el número convertido (o texto como 32°F)

Pasos de la función main

  1. Lee — obtiene el valor del input y la unidad.
  2. Validación JS — ¿es un número? ¿la unidad es "C" o "F"? Si no, mensaje de error.
  3. Llama a las funciones pertinentes — por ejemplo miFuncion(0, "C").
  4. Recibe la respuesta — lo que devuelve el return.
  5. Escribe en HTML — muestra el resultado en la página.

Patrón a memorizar

Usuario → formulario → main (lee, valida, llama, muestra) → función pequeña (calcula y return)

Ejemplo mental con temperatura

  1. La usuaria escribe 0 y C.
  2. La main lee y valida.
  3. La main llama miFuncion(0, "C").
  4. Esa función calcula y hace return → 32 o "32°F".
  5. La main escribe el resultado en el HTML.

La función main casi siempre se parece de un ejercicio a otro; lo que cambia es la función pequeña (contar caracteres vs. convertir grados).

5. Qué aprendes con este ejercicio

  • Parámetros — pasar datos a una función.
  • Condiciones — si es Celsius, una fórmula; si es Fahrenheit, la otra.
  • Cálculos con números.
  • return — devolver un valor a quien llamó a la función.
  • Integración en la web — formulario, validación y mostrar el resultado en HTML.

6. Cambios en el HTML (paso a paso)

Si partes del plantilla del calendario, adapta así:

  1. <title> y <h1> — título «Conversor de temperatura» y texto del enunciado.
  2. Instrucciones — «Escribe una temperatura, elige C o F y pulsa Convertir».
  3. Campo temperatura — quita numeroMes; añade type="number" con id="temperatura" y step="any" (permite decimales).
  4. Unidad — un <select id="unidad"> con <option value="C"> y <option value="F">, o radios con valores C/F.
  5. Botón — por ejemplo id="btnConvertir" y texto «Convertir».
  6. Salida — mantén id="mensaje" para el resultado (aria-live="polite" ayuda).
  7. Script — si el JS está en la carpeta js: <script src="js/app.js" defer></script>

Ids que debe coincidir con el JS

Elemento id sugerido
Input número temperatura
C / F unidad
Botón btnConvertir
Resultado mensaje

7. Estructura del JavaScript (js/app.js)

Todas las funciones en flecha. Orden obligatorio en el archivo:

1. DECLARACIÓN DE VARIABLES     → getElementById / querySelector
2. DECLARACIÓN DE FUNCIONES     → biblioteca + funcionMain
3. EJECUCIÓN DE CÓDIGO          → addEventListener("click", funcionMain)

7.1 Bloque 1 — Variables (enlaces con el HTML)

const inputTemperatura = document.getElementById("temperatura");
const selectUnidad = document.getElementById("unidad");
const btnConvertir = document.getElementById("btnConvertir");
const parrafoMensaje = document.getElementById("mensaje");

En comentarios a la derecha de cada línea: si es entrada DOM o salida DOM.

7.2 Bloque 2 — Funciones

Función principal: funcionMain — orquesta leer, validar, llamar biblioteca y escribir en #mensaje.

Biblioteca: funciones pequeñas con return; comentario a la derecha con entrada | salida | qué hace.

Función (flecha) Entrada Salida Qué hace
celsiusAFahrenheit número °C número °F celsius * 9/5 + 32
fahrenheitACelsius número °F número °C (f - 32) * 5/9
convertirTemperatura valor, "C" o "F" (origen) número convertido Elige la fórmula según origen
esTemperaturaValida string del input true / false No vacío y es número
esUnidadValida "C" o "F" true / false Solo acepta C o F
unidadDestino unidad origen "C" o "F" opuesta C → F, F → C
formatearResultado número, unidad destino string Ej. 32°F
funcionMain ninguna (lee DOM) ninguna (escribe DOM) Principal del ejercicio

Enunciado miFuncion(0, "C") → 32°F: el segundo parámetro es unidad de origen. Si es "C", conviertes a Fahrenheit.

7.3 Bloque 3 — Ejecución

btnConvertir.addEventListener("click", funcionMain);

Solo el listener aquí; la lógica va dentro de funcionMain y la biblioteca.

Flujo

Clic → funcionMain (principal)
         ├─ esTemperaturaValida / esUnidadValida
         ├─ convertirTemperatura → celsiusAFahrenheit | fahrenheitACelsius
         └─ formatearResultado → parrafoMensaje.textContent

Pruebas rápidas

Input Unidad Resultado esperado
0 C 32°F
32 F 0°C
(vacío) C Mensaje de error

Comentarios a la derecha (estilo del curso)

const celsiusAFahrenheit = (celsius) => {          // entrada: número °C | salida: número °F
  return celsius * (9 / 5) + 32;                   // aplica fórmula C → F
};

8. ¿Son funciones independientes?

En clase, independiente suele significar:

  • Recibe todo por parámetros (entrada → salida).
  • No usa getElementById ni .value del formulario por dentro.
  • No depende de variables globales del HTML.
  • Hace una sola cosa y devuelve con return.

Sí van en la biblioteca (independientes del DOM)

Función ¿Independiente? Por qué
celsiusAFahrenheit Sí Solo número → número
fahrenheitACelsius Sí Solo número → número
esTemperaturaValida Sí String → true/false
esUnidadValida Sí "C"/"F" → true/false
formatearResultado Sí Número + letra → texto
unidadDestino Sí Devuelve la unidad opuesta

convertirTemperatura

Llama a celsiusAFahrenheit o fahrenheitACelsius. Las tres son funciones separadas en la biblioteca, pero esta enlaza las otras. Si el profe pide que ninguna función llame a otra, quítala y en funcionMain haz el if (unidad === "C") y llama directamente a la fórmula que toque.

funcionMain — no es de biblioteca

Usa inputTemperatura, selectUnidad, parrafoMensaje y llama a varias funciones. Es la función principal de esta página, no una pieza que copies igual a otro ejercicio.
