1. Enunciado del ejercicio

Programar una función que devuelva el texto recortado según el número de caracteres indicados.

Ejemplo: miFunción("Hola Mundo", 4) → "Hola"

Además: validar los datos de entrada desde un formulario HTML.

  • Funciones flecha
  • Escuchadores (addEventListener)
  • Estructura en 4 bloques
  • Funciones independientes en biblioteca (reutilizables sin modificar)
  • Función funcionMain que conecta el HTML con la biblioteca

2. Idea de la profesora (método global)

3. Biblioteca de funciones (reutilizable)

Copia estas funciones a otra app sin modificarlas. No usan el HTML.

recortarTexto

Reutilizar en: títulos, bios, tweets, límite de caracteres 
const recortarTexto = (frase, numero) => frase.slice(0, numero);
Entrada: frase (string), numero (number)
Salida: string recortado
Ejemplo: recortarTexto("Hola Mundo", 4) → "Hola"

validarFrase

Reutilizar en: login, contacto, cualquier texto obligatorio 
const validarFrase = (frase) => {
  if (frase === "") {
    return "Introduce una frase.";
  }
  return "";
};
Entrada: frase (string)
Salida: mensaje de error o "" si OK

validarCantidad

Reutilizar en: edad, cantidad, longitud máxima ≥ 0 
const validarCantidad = (numero) => {
  if (Number.isNaN(numero) || numero < 0) {
    return "Introduce un número válido (0 o más).";
  }
  return "";
};
Entrada: numero (number)
Salida: mensaje de error o "" si OK

No copies tal cual a otra app: variables DOM, funcionMain y el addEventListener (adaptas ids y eventos).

4. Guía para otros ejercicios

  1. Identifica entradas y salida.
  2. Escribe biblioteca sin DOM.
  3. Escribe funcionMain: lee → valida → llama → escribe.
  4. En ejecución, solo addEventListener.
  5. Prueba datos correctos e incorrectos.

Código completo app.js

// IMPORTACIÓN DE MÓDULOS
// (sin módulos)

// DECLARACIÓN DE VARIABLES
const formtexto = document.getElementById("formtexto");
const texto = document.getElementById("texto");
const cantidad = document.getElementById("cantidad");
const resultado = document.getElementById("resultado");

// DECLARACIÓN DE FUNCIONES
const recortarTexto = (frase, numero) => frase.slice(0, numero);

const validarFrase = (frase) => {
  if (frase === "") return "Introduce una frase.";
  return "";
};

const validarCantidad = (numero) => {
  if (Number.isNaN(numero) || numero < 0) {
    return "Introduce un número válido (0 o más).";
  }
  return "";
};

const funcionMain = (evento) => {
  evento.preventDefault();
  const frase = texto.value.trim();
  const numero = Number(cantidad.value);
  const errorFrase = validarFrase(frase);
  if (errorFrase !== "") {
    resultado.textContent = errorFrase;
    return;
  }
  const errorCantidad = validarCantidad(numero);
  if (errorCantidad !== "") {
    resultado.textContent = errorCantidad;
    return;
  }
  resultado.textContent = recortarTexto(frase, numero);
};

// EJECUCIÓN DE CÓDIGO
formtexto.addEventListener("submit", funcionMain);

8. Test — 15 preguntas

Haz clic en cada pregunta para ver la respuesta. Intenta responder antes de abrir.
1. ¿Qué devuelve recortarTexto("Hola Mundo", 4)?
Devuelve "Hola". Usa slice(0, 4): cuatro caracteres desde el inicio. Equivale al enunciado miFunción("Hola Mundo", 4).
2. ¿Cuáles son las dos entradas del ejercicio?
La frase (#texto) y la cantidad (#cantidad). En código: texto.value.trim() y Number(cantidad.value).
3. ¿Dónde se muestra la salida?
En #resultado con resultado.textContent. Ahí va el texto recortado o el mensaje de error.
4. ¿Qué hace evento.preventDefault()?
Evita que el formulario recargue la página al enviar. Sin esto no verías el resultado en pantalla.
5. ¿Por qué validarFrase devuelve "" cuando está bien?
"" significa sin error. En funcionMain se usa if (errorFrase !== "") para mostrar mensaje y hacer return.
6. ¿Diferencia entre biblioteca y funcionMain?
Biblioteca: solo parámetros y return; reutilizable. funcionMain: lee DOM, llama biblioteca, escribe HTML; cambia en cada proyecto.
7. ¿Qué evento y elemento escucha addEventListener?
Evento "submit" en el formulario formtexto (botón Recortar).
8. ¿Por qué Number(cantidad.value)?
.value siempre es string. Number() convierte a número para isNaN y slice.
9. ¿Qué hace trim()?
Quita espacios al inicio y final. " Hola " pasa a "Hola".
10. ¿Qué comprueba validarCantidad?
Que sea número válido (!Number.isNaN) y que no sea negativo. Si falla, devuelve el mensaje de error.
11. ¿Por qué la biblioteca no usa getElementById?
Para ser independiente del HTML y copiarla a otra app sin cambiarla. Solo parámetros y return.
12. ¿Las cuatro secciones del app.js?
1. Importación 2. Variables (getElementById) 3. Funciones (biblioteca + main) 4. Ejecución (addEventListener).
13. ¿Frase vacía y pulsar Recortar?
validarFrase devuelve mensaje, se muestra en resultado, return impide recortarTexto.
14. ¿Copiar todo app.js a otra app sin cambiar?
No todo. Biblioteca sí. Variables, funcionMain y listener se adaptan al nuevo HTML.
15. Los 5 pasos de funcionMain
1. Lee 2. Valida 3. Llama biblioteca 4. Recibe return 5. Escribe en HTML.
El ejercicio separa una biblioteca reutilizable de una funcionMain y un escuchador que conectan con este formulario.
