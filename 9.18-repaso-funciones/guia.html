Guide de l'exercice : Pairs et impairs

Explication simple, comme en cours — sans prérequis en programmation.

De quoi parle l'exercice ?

Imagine que tu as une liste de nombres, par exemple :

1, 2, 3, 4, 5, 6, 7, 8, 9, 0

L'exercice te demande de les trier en deux groupes :

  • Les nombres pairs — ceux qu'on peut diviser par 2 sans reste.
    Exemples : 2, 4, 6, 8, 0
  • Les nombres impairs — ceux qui, divisés par 2, laissent un reste.
    Exemples : 1, 3, 5, 7, 9

C'est quoi une « fonction » ?

Une fonction, c'est comme une petite machine :

  • Tu lui donnes quelque chose (une entrée)
  • Elle fait un travail
  • Elle te rend un résultat

Dans cet exercice :

  • Entrée : la liste de nombres
  • Travail : séparer pairs et impairs
  • Résultat : un objet avec deux listes

C'est quoi un « array » (tableau) ?

Un tableau, c'est une liste ordonnée de valeurs, entre crochets : 

[1, 2, 3, 4, 5]

Chaque nombre a sa place, comme des cases numérotées.

C'est quoi un « objet » ?

Un objet, c'est comme une fiche avec des étiquettes.

Au lieu d'une seule liste, tu as plusieurs listes nommées : 

{
  pares: [2, 4, 6, 8, 0],
  impares: [1, 3, 5, 7, 9]
}
  • pares → la liste des pairs
  • impares → la liste des impairs

C'est plus clair qu'une seule liste mélangée.

En une phrase

L'exercice consiste à créer une fonction qui prend une liste de nombres et la sépare en deux listes : une pour les pairs, une pour les impairs.

Petite astuce pour reconnaître pair / impair

  • Pair : divisible par 2 (2, 4, 6, 8, 0…)
  • Impair : pas divisible par 2 (1, 3, 5, 7, 9…)

Attention : le 0 est pair — c'est une règle importante à retenir.

Exemple de code

function miFuncion(numeros) {
    const pares = [];
    const impares = [];

    for (const numero of numeros) {
        if (numero % 2 === 0) {
            pares.push(numero);
        } else {
            impares.push(numero);
        }
    }

    return { pares, impares };
}

console.log(miFuncion([1, 2, 3, 4, 5, 6, 7, 8, 9, 0]));
// { pares: [2, 4, 6, 8, 0], impares: [1, 3, 5, 7, 9] }
